# 🧠 Computational Thinking for Engineering

---

## 🚀 Sobre o Projeto

Este repositório reúne minha jornada de aprendizado na disciplina de **Computational Thinking for Engineering**, explorando conceitos fundamentais de programação e lógica computacional.

Durante as aulas, são desenvolvidos exercícios, atividades e práticas utilizando **Python**, com foco na construção de uma base sólida em programação e resolução de problemas.

O conteúdo também serve como base para áreas futuras como:

* 📊 Ciência de Dados
* 🤖 Inteligência Artificial
* 🧱 Engenharia de Dados
* 💻 Desenvolvimento de Software

---

## 🧠 Objetivo

✔️ Desenvolver pensamento computacional
✔️ Aprender lógica de programação
✔️ Praticar resolução de problemas
✔️ Desenvolver aplicações utilizando Python
✔️ Construir uma base para projetos futuros

---

## ⚙️ Conteúdos Abordados

* 🔢 Variáveis e tipos de dados
* ➕ Operadores
* ⌨️ Entrada e saída de dados
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição

* 🔤 Manipulação de Strings
